# Les neuf cas du projet

Une page par cas : le contexte, qui utilise l'appli, la décision à éclairer, les colonnes du fichier, ce qu'il faut savoir avant de commencer et des questions métier possibles. Les fichiers eux-mêmes sont dans [`data/projets/`](../../data/projets/LISEZMOI.md).

| Cas | Qui décide quoi | Données |
|---|---|---|
| [1 · OLD et véloroutes du Loiret](01-old-veloroutes.md) | le Département : quels tronçons de véloroute débroussailler en premier | 1 564 morceaux de tronçon, 324 km |
| [2 · Collèges du Loiret](02-colleges.md) | le Département : où agrandir un collège, quel secteur redessiner | 70 collèges × 10 rentrées |

| [5 · Sécurité routière dans le Loiret](05-securite-routiere.md) | la préfecture : où et quand cibler les contrôles | 3 242 accidents, 2019-2025 |

Les cas 1 à 3 viennent du Département du Loiret, à partir de son catalogue GéoLoiret. Un cas peut être pris par deux groupes s'ils soutiennent deux décisions différentes. Vous pouvez aussi venir avec vos propres données, ou celles de votre entreprise (voir le README du dépôt). Les questions de chaque page sont des pistes : votre appli en soutient une ou deux, pas toutes.
