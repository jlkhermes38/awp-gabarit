# Les six cas du projet

Une page par cas : le contexte, qui utilise l'appli, la décision à éclairer, les colonnes du fichier, ce qu'il faut savoir avant de commencer et des questions métier possibles. Les fichiers eux-mêmes sont dans [`data/projets/`](../../data/projets/LISEZMOI.md).

| Cas | Qui décide quoi | Données |
|---|---|---|
| [1 · Énergie en Centre-Val de Loire](01-energie.md) | l'acheteur d'énergie d'une collectivité : quand décaler la recharge de sa flotte | 52 603 demi-heures, 2023-2026 |
| [2 · Sécurité routière dans le Loiret](02-securite-routiere.md) | la préfecture : où et quand cibler les contrôles | 3 242 accidents, 2019-2025 |

| [5 · E-commerce au Brésil](05-e-commerce.md) | le directeur e-commerce : quels vendeurs corriger d'abord | 110 189 articles, 10 890 avis négatifs |
| [6 · Territoire du Loiret](06-territoire-loiret.md) | un élu : où soutenir une maison de santé | 325 communes |

Un cas peut être pris par deux groupes s'ils soutiennent deux décisions différentes. Les questions de chaque page sont des pistes : votre appli en soutient une ou deux, pas toutes.
